## Run the starter

Use Node.js 24 LTS and npm for these commands:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and edit
`src/pages/index.js`. The starter currently pins Next.js 15.5.24 and React 18.2.0
and has no committed dependency lockfile or package-manager pin. `npm install`
resolves the remaining version ranges; it is not a frozen install. Follow the
video to build the portfolio and add its tutorial dependencies, or use the
completed repository's README for its separate Bun setup and newer library
versions.

The available checks and local production preview are:

```bash
npm run lint
npm run build
npm run start
```

Run `npm run start` after a successful build; development and production preview
both use port 3000 by default. No application environment variables or API keys
are required. Dependency installation needs registry access, and the starter's
`next/font/google` Inter font also needs access to Google Fonts when building.
The completed project bundles its font locally instead.

Before publishing your own portfolio, replace sample text, links, contact
addresses, profile images, and `public/dummy.pdf` with your own content. Preserve
asset credits and check the terms for any assets you keep. No project-wide
license is currently declared in this repository.
